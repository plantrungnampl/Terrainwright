# Security Policy

## Supported versions

Terrainwright 1.0.x receives security fixes. Older development snapshots are not supported.

## Reporting a vulnerability

Do not disclose exploit details in a public issue, Discussion, pull request, or social post before a fix is available.

Use [GitHub private vulnerability reporting](https://github.com/plantrungnampl/Terrainwright/security/advisories/new) and include:

- affected Terrainwright, Minecraft, Fabric Loader, Fabric API, and Java versions;
- whether the issue affects clients, dedicated servers, or both;
- minimal reproduction steps or a proof of concept;
- expected impact and any known mitigation;
- relevant logs with tokens, usernames, server addresses, and private world data removed.

You should receive an acknowledgement within seven days. Maintainers will validate the report, coordinate a fix and release, and credit reporters who want attribution. Please allow time for users and server operators to update before publishing full technical details.
